## 🛠️ Công nghệ

- **Zero-Dependency:** Sử dụng HTML5 Semantic, CSS hiện đại và Vanilla JavaScript kết hợp Impress.js 3D không cần thư viện nặng.
- Không cần cài đặt node_modules hay build step phức tạp.
- Tương thích tối ưu với chế độ chia đôi màn hình (Split Screen) khi học viên vừa xem lý thuyết vừa thực hành trực tiếp trên Google Docs.

## 🚀 Hướng dẫn Triển khai GitHub Pages

Repository đã cấu hình sẵn GitHub Actions tự động deploy khi push lên nhánh `main`:
1. Vào repository trên GitHub: **Settings** -> **Pages**.
2. Tại mục **Build and deployment** -> **Source**, chọn **GitHub Actions** (hoặc **Deploy from a branch** -> nhánh `main` / root).
3. Trang web sẽ được phát hành tại: `https://langtuc0der.github.io/G-2_GoogleDocss/`.
